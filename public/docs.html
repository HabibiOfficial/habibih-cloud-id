Overview

HABI API menyediakan REST API berformat JSON untuk mendownload media dari berbagai platform sekaligus menyediakan sejumlah tools pemrosesan teks dan gambar.

ItemNilai
Base URLhttps://api.habi.my.id
Pfad API/api
MethodGET
Formatapplication/json (kecuali endpoint file)
AutentikasiQuery parameter &apikey=KEY
Rate limit25 request/hari (gratis)

Autentikasi

Semua endpoint wajib menyertakan apikey. Key didapat gratis lewat endpoint register. Tanpa key atau dengan key yang salah, server membalas 401.

Daftarkan Key

Request
GET https://api.habi.my.id/api/register?note=nama-kamu
Respons: {"status":true,"apikey":"HABI-1AE28878F6D6","limit":"25 req/hari","note":"Upgrade premium hubungi owner"}

Cek Endpoint Massal

Ada script smoke test yang mengecek seluruh endpoint sekaligus — status, content-type, auth gate, dan proteksi SSRF. Jalankan kapan saja sebelum deploy.

Terminal
# produksi
npm run smoke

# server lokal / target lain
npm run smoke -- https://api.domain-kamu.com

# pakai key tertentu
API_KEY=HABI-XXXX npm run smoke
Exit code: 0 semua lolos, 1 ada endpoint yang gagal. Berguna untuk CI/CD — kalau smoketest gagal, deploy jangan diteruskan.

Gunakan Key

Request
GET https://api.habi.my.id/api/ytmp3?url=https://youtu.be/VIDEO_ID&apikey=HABI-1AE28878F6D6
Catatan: parameter note bersifat opsional. API key bersifat rahasia — jangan bagikan ke publik atau commit ke repository.

Format Respons

Semua respons memakai field status sebagai penanda berhasil atau gagal.

Berhasil

JSON
{
  "status": true,
  "title": "Rick Astley - Never Gonna Give You Up",
  "duration": 213,
  "url": "https://api.habi.my.id/api/file?id=..."
}

Gagal

JSON
{
  "status": false,
  "error": "APIkey tidak valid. Daftar dulu: /api/register"
}

Kode Error

500Gagal di sisi serverCoba lagi, cek URL yang dimasukkan
504TimeoutServer sedang sibuk, coba lagi beberapa saat

🎨 Image Tools

Semua gambar digambar langsung di server kami memakai @napi-rs/canvas. Tidak ada permintaan ke layanan eksternal, jadi selalu tersedia dan gratis.

GET

/api/brat

Gratis

Buat gambar brat (meme hijau ikonik) dari teks. Mendukung emoji.

Parameter

ParameterTipeWajibKeterangan
textstringYaTeks pada gambar. Maks 200 karakter
blurnumberTidakNilai blur. Default 0
downloadbooleanTidak1 untuk paksa unduh
cURL
curl "https://api.habi.my.id/api/brat?text=Halo+HABI+API&apikey=API_KEY" -o brat.png
Output: file PNG 500×500 pixels.
GET

/api/bratvid

Gratis

Buat video MP4 dari teks brat. Dihasilkan di server memakai ffmpeg.

Parameter

ParameterTipeWajibKeterangan
textstringYaTeks pada video. Maks 120 karakter
formatstringTidakmp4 (default) atau webm
durationnumberTidakDurasi detik. Default 2, maks 10
fpsnumberTidakFrame per detik. Default 15
width / heightnumberTidakUkuran. Default 500×500
cURL
curl "https://api.habi.my.id/api/bratvid?text=Halo&duration=2&apikey=API_KEY" -o brat.mp4
Output: file MP4. Render butuh 1–3 detik.
GET

/api/iqc

Gratis

Buat screenshot chat iPhone (iPhone Quote). Cocok untuk pesan lucu atauPLSQUO.

Parameter

ParameterTipeWajibKeterangan
textstringYaIsi pesan. Mendukung baris baru dan emoji
timestringTidakJam pada status bar. Default 09.41
batteriesstringTidakLevel baterai, mis 87%
menubooleanTidakTampilkan menu Balas/Teruskan. Default true. Set false untuk versi bersih
operator / timebar / wifibooleanTidakTampilkan elemen tersebut
cURL
# Versi lengkap dengan menu konteks (default)
curl "https://api.habi.my.id/api/iqc?text=Halo&time=2:21&apikey=API_KEY" -o chat.png

# Versi bersih tanpa menu
curl "https://api.habi.my.id/api/iqc?text=Halo&menu=false&apikey=API_KEY" -o chat-clean.png
Output: file PNG 680 px lebar. Default-nya sudah termasuk menu konteks (Balas, Teruskan, Salin, dst) supaya hasilnya terlihat natural seperti screenshot WhatsApp asli.
GET

Buat meme dengan teks atas dan bawah. Cocok untuk gambar yang sudah kamu punya.

Parameter

Output: file PNG. Teks otomatis membungkus dan diberi outline hitam agar terbaca.
GET

/api/watermark

Gratis

Tambahkan teks watermark ke gambar. Posisi dan opacity bisa diatur.

Parameter

ParameterTipeWajibKeterangan
imagestringYaURL atau base64 gambar
textstringTidakTeks watermark. Default HABI API
positionstringTidakbr (default), bl, tr, tl
opacitynumberTidak0.1–1. Default 0.75

GET

/api/humanizer

Gratis

Ubah teks yang terlalu kaku ala AI menjadi lebih natural. Berbasis aturan, jalan offline — tidak memanggil LLM.

Parameter

ParameterTipeWajibKeterangan
textstringYaTeks yang akan ditulis ulang. Maks 20.000 karakter
modestringTidakindo (default) atau en
cURL
curl -G "https://api.habi.my.id/api/humanizer" --data-urlencode "text=It is important to note that..."
Contoh perubahan: It is important to note that → Perlu dicatat bahwa, Furthermore → Selain itu, utilize → pakai
Catatan: ini bukan AI generatif. Hanya mengganti pola kata dan frasa kaku yang umum dipakai model bahasa.

/api/spotify

Gratis

Cari lagu Spotify lalu kumpulkan tautan YouTube untuk diunduh. Spotify memakai DRM, jadi audio diambil dari YouTube dengan pencocokan judul + artis.

cURL
curl "https://api.habi.my.id/api/spotify?url=https://open.spotify.com/track/TRACK_ID&apikey=API_KEY"
Cara pakai 2 langkah:
1) Panggil /api/spotify → dapat matched.url
2) Pakai matched.url ke /api/ytmp3 untuk mengunduh audionya
Respons: {"status":true,"source":"spotify","title":"...","artist":"...","matched":{"title":"...","duration":212,"uploader":"...","url":"https://youtube.com/watch?v=...","confidence":"high"}}

🆕 Studio

Endpoint baru yang dijalankan sepenuhnya di server kami — yt-dlp untuk resolver, @napi-rs/canvas untuk gambar. Semua wajib apikey, sudah termasuk proteksi anti-SSRF dan batas ukuran berkas.

GET

/api/resolve

Gratis

Ambil URL media siap pakai dari link TikTok, Facebook, Instagram, X, YouTube, Reddit, dan lain-lain. Mengembalikan JSON, bukan file — cocok kalau bot kamu butuh link untuk dikirim ulang, bukan file video.

Parameter

ParameterTipeWajibKeterangan
urlstringYaLink media yang mau diambil
audiobooleanTidaktrue = ambil stream audio saja
cURL
curl "https://api.habi.my.id/api/resolve?url=https://www.tiktok.com/@user/video/ID&apikey=API_KEY"
Respons: {"status":true,"platform":"tiktok","source":"yt-dlp","title":"...","thumbnail":"...","media":{"video":{"url":"...","ext":"mp4"},"audio":null}}
Catatan: untuk mau file video langsung, pakai /api/tiktok atau /api/facebook yang sudah mengembalikan MP4. Endpoint ini mengembalikan JSON. Jalur-taking: yt-dlp → tikwm (khusus TikTok) → gateway fallback.
GET

/api/detect

Respons: {"status":true,"platform":"tiktok","url":"..."} — nilai platform bisa: tiktok, facebook, instagram, twitter, youtube, soundcloud, pinterest, reddit, vk, douyin, other.
