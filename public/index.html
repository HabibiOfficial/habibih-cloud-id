FAQ

Pertanyaan Umum

Apakah API ini gratis?

Ya. Setiap key baru mendapat kuota gratis 25 req/hari tanpa batas waktu. Kalau kuota habis, tunggu reset di hari berikutnya. Untuk kebutuhan lebih besar, hubungi owner untuk paket premium.

Bagaimana cara upgrade ke premium?

Hubungi owner lewat WhatsApp. Paket premium menambah kuota harian, prioritas antrean, dan akses endpoint eksklusif. Buka halaman harga untuk detail paketnya.

Format responsnya apa?

Selalu JSON dengan field status. Kalau sukses, status: true disertai data. Kalau gagal, status: false disertai error berisi pesan. Endpoint yang mengembalikan file (gambar, audio, video) langsung mengirim biner.

Kenapa saya dapat error "APIkey tidak valid"?

Pastikan parameter apikey ditulis lengkap dan tidak ada spasi. Kalau key kamu habis kuota,，好好 tunggu reset harian atau hubungi owner untuk upgrade.

Apakah boleh dipakai untuk bot WhatsApp?

Boleh, termasuk untuk bot pribadi maupun bot grup. Yang dilarang: menjual ulang layanannya,quita在前/share endpoint-nya sebagai produk jadi, dan menyalahgunakan API untuk hal yang melanggar hukum.

Kenapa YouTube Sometimes gagal?

YouTube aktif memblokir beberapa datacenter IP. Kalau sebuah video gagal, coba endpoint /api/direct atau tunggu beberapa saat lalu ulangi. Link yang butuh login (privat/.member) tidak bisa diakses.
